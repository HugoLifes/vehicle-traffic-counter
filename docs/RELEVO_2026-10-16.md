## 1. Qué es y para quién

Plataforma de **aforo vehicular** (conteo de vehículos en video) para una
empresa independiente de estudios de tránsito en Cd. Juárez, que es del tío
del usuario.
- La meta es **entregarle un producto confiable que opere solo y pueda
  crecer**, no afinar cifras por afinarlas.
- No hay presupuesto para cámaras nuevas: la precisión sale del software y de
  configurar mejor las cámaras que ya tienen.

- **Proyecto en la PC:** `D:\vehicle-traffic-counter`
- **Repositorio:** https://github.com/HugoLifes/vehicle-traffic-counter (rama `master`)
- **Equipo de producción:** Jetson Orin Nano.
  - Dirección: `apia@10.197.1.156`, checkout en `~/vehicle-traffic-counter`.
  - Contenedor `aforo-vehicular`, puerto 8080.
- **Dirección pública** (la usan los que prueban): https://apia-vision.tail2bdded.ts.net
  - Es por Tailscale y va lenta: ~4.5 Mb/s.

## 4. El hallazgo pendiente: dobles conteos en Fraccionamiento

La revisión marcó 276 "posibles dobles" en el proyecto 27. Se miraron 16 a ojo
(hoja en el scratchpad de la sesión, no en el repo), y en **la mayoría es el
mismo vehículo**: primero se detecta un pedazo y unos cuadros después el
vehículo entero, con otro número de rastro y unos 5–9 cuadros de diferencia.

| línea · sentido | cruces | posibles dobles |
|---|---|---|
| 1 · Avenida, norte · entra | 1 497 | 72 (4.8 %) |
| 1 · Avenida, norte · sale | 3 171 | 37 (1.2 %) |
| 3 · Avenida, sur · entra | 2 830 | 142 (5.0 %) |
| 3 · Avenida, sur · sale | 1 041 | 24 (2.3 %) |

- **Cuidado: es la trampa de cancelación.** La línea 1 "entra" (el carril
  tapado, umbral 0.10) da 1_3 = 151 contra 180 del conteo a mano. Si hay
  dobles, la pérdida real es mayor de lo que parece.
- **El entregable no se tocó.**
- Para seguir:
  1. revisar en la pestaña Revisar de 27 una muestra de cada línea:
     confirmar o descartar;
  2. medir qué fracción son de verdad el mismo vehículo;
  3. si es alta, la causa probable es el rastreador con umbral 0.10, que
     abre un rastro nuevo para el pedazo. El arreglo va del lado del conteo
     (p. ej. no contar un rastro nuevo que nace encimado sobre uno que ya
     cruzó). **Medirlo sin GPU** con las detecciones guardadas
     (`data/fr/det_08_*.json` en el Jetson) y contra el conteo a mano antes
     de recontar nada;
  4. preguntar al usuario antes de recontar o de descartar en bloque: es un
     proyecto entregado.

## 6. Cómo se trabaja aquí (no saltarse)

- **Desplegar código Python** (`src/` y `tools/` se montan de solo lectura):
  ```bash
  git push   # desde la PC
  ssh apia@10.197.1.156 "cd ~/vehicle-traffic-counter && git pull && docker compose -f docker-compose.jetson.yml restart aforo-vehicular"
  ```
- **Un cambio de `web/`** necesita reconstruir la imagen, y después limpiar:
  ```bash
  docker compose -f docker-compose.jetson.yml build aforo-vehicular
  docker compose -f docker-compose.jetson.yml up -d aforo-vehicular
  docker builder prune -f
  docker image prune -f
  ```
- **Antes de reiniciar**, comprobar que no haya nada en la cola de la GPU
  (`video_jobs.status` 'queued' o 'processing', `anotado_estado`,
  `diag_estado`) ni una subida en curso. Nunca `--remove-orphans`.
- **Correr algo dentro del contenedor:** pasar el script por stdin con
  ```bash
  ssh apia@10.197.1.156 "docker exec -i -w /app aforo-vehicular python3 -" < script.py
  ```
  - Solo `data/` es escribible.
  - Para la API desde dentro: Basic con `AFORO_USUARIO` y `AFORO_CONTRASENA`
    del entorno. **No imprimirlas.**
- **Probar sin tocar producción:** se baja una copia consistente de la base
  con `sqlite3.backup` desde el contenedor y se apunta
  `traffic_db.DB_PATH` a la copia. Así se comprobó la regla de clases.
- **Un solo trabajo de GPU a la vez** en el Orin.
- **Procesar video solo en el Jetson.** Nunca en la PC.
- **No recontar ni borrar datos** de los proyectos 7, 9, 26, 27 y 28 sin
  preguntar. Hay respaldos diarios en `data/respaldos/`.
- **Nunca borrar videos** que la plataforma no copió ella misma.
- **`.env` nunca se commitea.** Antes de cada commit:
  ```bash
  git check-ignore -v .env
  ```
- **Medir antes de afirmar, y mirar el cuadro antes de concluir.** Una sola
  hora o condición de luz no valida nada.
- **No escribir contraseñas** en sitios ni correr `sudo`: se le dan los
  comandos al usuario. Instalar software lo bloquea el modo de permisos, así
  que se le pasan los comandos.
